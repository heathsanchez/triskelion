# DI autonomy / answer-leakage audit

This document exists to prevent a polished transfer result from being mistaken for autonomous development.

## Classification

- **A — autonomous construction:** the needed abstraction/operator/representation is not supplied by the experimenter; the system constructs it from exposed evidence and it survives protected causal tests.
- **B — construction inside a supplied meta-language:** the exact solution is not supplied, but the experimenter supplies a language known to contain it.
- **C — supplied abstraction, autonomous selection/composition:** useful evidence for routing/composition, not invention.
- **D — human-designed intervention demonstrated causally:** useful mechanism evidence, not autonomous learning.

## Why DI_BLIND_V1 is different

`DI_BLIND_V1_AUTONOMOUS_CONSTRUCTION` is intentionally narrower than the full Developmental Intelligence thesis, but it removes the central answer-leakage objection.

The proposer gets a fresh independent checker, one mechanically selected failing case, generic source text, and executable consequences. It gets no target-specific repair primitive or human-authored semantic hypothesis. Its only mutation language is a generic exact source replacement. All candidates are generated before hidden evaluation. A candidate must then survive hidden regression, protected transfer, and physical remove/restore ablation.

If V1 fails, record the negative. Do not add a human hint and rerun under the same experiment identity.

If V1 passes, it establishes bounded autonomous capability construction from experience. It still does **not** establish the deepest DI claim.

The next crown-jewel gate is conditional compounding:

> autonomously acquired O1 must change the later discovery process so that O2 becomes reachable under a matched budget where cold/raw-memory controls cannot reach it.

That is the point where the evidence moves from "the agent repaired itself" toward "what it learned changed what it could learn next."

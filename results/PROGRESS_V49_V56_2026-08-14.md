# Triskelion Progress Ledger — V49 through V56

_Date: 2026-08-14 NZST_

This file reconciles the newest external-capability, compounding, historical-world, constructor-level, and model-integration experiments. It is intentionally conservative: harness crashes are not scientific negatives, and incomplete historical runs are not promoted to passes.

## V49 — temporally sealed transfer and revocation — PASS

V49 separated calibration from transfer in time. The learned capability/category was committed before the Requests target was opened. On the withheld Requests target the cold state failed, the committed capability repaired the target, and ablation restored failure. Only after transfer evaluation was complete was later counterevidence opened; that evidence contradicted the retained scope and triggered revocation.

Canonical causal pattern:

`calibrate -> commit -> open sealed target -> cold FAIL -> warm PASS -> ablate FAIL -> open later contradiction -> revoke`

Verdict: `PASS_V49_TEMPORALLY_SEALED_TRANSFER_RATCHET`.

## V50 — verifier-generated HELP/HARM labels — PASS

V50 removed another designer-provided signal. Calibration episode labels were generated from executable verifier transitions rather than supplied as positive/negative classes. Two HELP and two HARM episodes uniquely identified the relevant relation, which was committed before Requests was opened. Requests then matched the frozen relation and produced HELP; later Django evidence matched the same relation but produced HARM, causing revocation.

Verdict: `PASS_V50_OUTCOME_LABELED_SEALED_RATCHET`.

## V51 — operator construction outside frozen old closure — PASS

V51 froze an old algebra containing only token-position/permutation generators. These preserve token-value multisets. The required transformation changes that invariant, giving a concrete obstruction to old closure.

From a generic token-emission substrate, two independent external obstructions had multiple local successful replacements, but their unique common repair was:

`< -> <=`

The resulting operator was therefore constructed from cross-episode executable evidence rather than supplied as a named primitive. Its applicability scope was learned separately from HELP/HARM evidence. Requests remained sealed until phase B.

On the unseen Requests target:

- cold target: FAIL;
- constructed operator applied in learned scope: PASS;
- operator ablation: FAIL.

Later independent HARM evidence landed inside the learned scope. Refinement was attempted; no admissible refinement survived in the frozen scope language, so the rule was revoked.

Verdicts:

- `PASS_V51_PHASE_A_OPERATOR_CONSTRUCTION`
- `PASS_V51_SEALED_OPERATOR_INVENTION_RATCHET`

Claim boundary: the operator is outside the frozen old effective closure, but construction still occurs inside a supplied generic meta-language.

## V54 — two-generation operator compounding — PASS

V54 closed the main operator-level developmental capstone.

Generation 1 constructed a genuinely old-closure-expanding operator O1. A later Requests target was made two innovations deep under a frozen one-new-generator horizon.

Before O1, no one-rewrite successor solved the target:

`O2 not discoverable under A0 budget`.

After lawful reuse of O1, exactly one new operator became discoverable:

`O2: and -> or`.

Execution gates:

- A0: FAIL;
- A0 + O1: FAIL;
- A0 + O1 + O2: PASS;
- retain O2 but ablate O1: FAIL.

Thus, in the frozen bounded protocol:

`O1 notin Closure(A0)`

and

`O2 notin Discoverable(A0)` but `O2 in Discoverable(A0 + O1)`.

Verdict: `PASS_V54_TWO_GENERATION_COMPOUNDING`.

This is bounded causal evidence that one verified invention can change which genuinely new invention becomes discoverable next.

## V56C — structurally verifier-controlled model layer — PASS

V56C tested the architectural correction suggested by V55C. The model proposes an action, but explicit structural verification remains authoritative over whether the capability is allowed to fire.

Same small Qwen family, same 12-case bounded decision problem:

- no memory: 6/12;
- raw memory: 6/12;
- verifier-controlled capability layer: 12/12.

All six helpful cases were admitted correctly and all six protected cases were preserved. The model frequently proposed KEEP; the explicit verifier-controlled layer overrode it to WIDEN precisely when executable boundary evidence allowed the transformation.

Verdict: `PASS_V56C_VERIFIER_MODEL_LAYER`.

Architectural conclusion supported by this bounded test:

`model proposes -> explicit capability/scope layer -> external verifier -> admit/block`

The verifier belongs in the execution/control path, not only in training or memory admission.

## Current strongest synthesis

The bounded explicit developmental mechanism now has evidence for:

1. closure-before-invention;
2. explicit composition and hierarchy;
3. operator construction outside a frozen old effective closure;
4. learned applicability scope;
5. temporally sealed source-distinct causal transfer;
6. cold -> warm -> ablation causal dependence;
7. verifier-derived HELP/HARM supervision;
8. later revision/revocation;
9. one verified invention changing what new operator becomes discoverable next;
10. verifier-controlled augmentation of a fixed small coding model on a bounded applicability test.

The major unresolved scientific frontiers are now narrower:

- **Natural historical replication:** reproduce the V51/V54 chain on naturally occurring historical failures with enough clean worlds and broader localization/construction coverage.
- **Constructor-level growth:** establish `Constructible(K0) subsetneq Constructible(K1)` and ideally a two-generation K1 -> K2 causal lineage. V55B is a negative for one meta-substrate; V56B did not reach a verdict.
- **Scale/external value:** move the verifier-controlled model-layer result beyond the 12-case smoke benchmark to meaningful coding-agent workloads under matched budgets.

## Claim boundary

Do not claim unrestricted operator invention, unrestricted constructor invention, a universal cognitive algebra, or open-ended self-improvement. The strongest justified statement is that **under frozen bounded executable protocols, verified experience can construct capabilities absent from the old effective closure, govern their applicability and revocation, and causally expand the discoverability of later capabilities.**

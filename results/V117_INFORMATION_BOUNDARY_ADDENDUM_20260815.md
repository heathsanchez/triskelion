# V117 information-boundary addendum

V117 is prospective with respect to the **K1 implementation and acquisition qualification**, but it is **not a sealed/unseen-target transfer experiment**.

Before V117 was frozen, the existing Specimen `StrataLexprGen.lean` file had already been inspected. That file explicitly documents the higher-universe structure-parameter limitation and the `LExprU` monomorphic workaround. Therefore the later Strata target is source-distinct and natural, but its broad failure mode is known in advance.

Consequences for claim language:

- Allowed: `prospective constructor implementation`, `source-distinct natural transfer`, `real Lean metaprogramming target`, `causal ablation`.
- Not allowed: `sealed target`, `unseen failure mode`, `blind held-out discovery`.

A V117 pass can establish that a generic constructor mechanism developed on an independent acquisition fixture transfers to the real Strata case. It cannot establish that the mechanism itself was discovered without any knowledge of the target failure family.

This addendum does not change the frozen gates; it narrows the admissible interpretation before execution.

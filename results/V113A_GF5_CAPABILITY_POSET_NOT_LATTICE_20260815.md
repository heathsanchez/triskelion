# V113A — GF(5) Developmental Poset; Lattice Hypothesis Falsified

Date: 2026-08-15 NZST

Status: deterministic post-V113 structural analysis. This is **not** a separately precommitted prospective experiment.

## Input

V113 found 12 old-unit orbits but only 7 exact developmental closure identities in the GF(5) unary world.

Write the seven developmental classes as:

- `D0 = {orbit 0}` — closure size 125
- `D1 = {orbit 1}` — closure size 225
- `D2 = {orbits 2,3}` — closure size 925
- `D3 = {orbits 4,5}` — closure size 925
- `D4 = {orbits 6,9}` — closure size 625
- `D5 = {orbits 7,8,10}` — closure size 3025
- `D6 = {orbit 11}` — closure size 125

Define developmental order by exact reachability:

`Di <= Dj` iff a representative of `Di` is contained in the exact capability closure generated by old affine capability plus a representative of `Dj`.

Because V113 verified mutual reachability iff exact closure equality, this order is well-defined on developmental classes.

## Exact order

All non-reflexive reachability relations are:

- `D0 <= D2`
- `D0 <= D3`
- `D0 <= D4`
- `D0 <= D5`
- `D1 <= D2`
- `D1 <= D3`
- `D1 <= D4`
- `D1 <= D5`
- `D2 <= D5`
- `D3 <= D5`
- `D4 <= D5`

`D6` is incomparable with every other non-identical developmental class.

The transitive reduction / Hasse edges are:

- `D0 -> D2`
- `D0 -> D3`
- `D0 -> D4`
- `D1 -> D2`
- `D1 -> D3`
- `D1 -> D4`
- `D2 -> D5`
- `D3 -> D5`
- `D4 -> D5`

So the connected nontrivial component has the form:

```text
             D5
           /  |  \
         D2   D3  D4
         |\\  /|  /|
         | \/ | / |
         | /\ |/  |
         D0   D1
```

with `D0` and `D1` both below each of the three mutually incomparable middle classes `D2,D3,D4`.

`D6` is isolated from this component under the tested one-generator developmental order.

## Important negative result — this is NOT a lattice

The broad phrase **capability lattice** is false in this exact GF(5) developmental structure.

Consider `D0` and `D1`.

Their common upper bounds include:

- `D2`
- `D3`
- `D4`
- `D5`

But `D2`, `D3`, and `D4` are mutually incomparable. Therefore there is no unique least upper bound / join of `D0` and `D1`.

Hence the developmental partial order is **not a lattice**.

This is a useful falsification of the terminology suggested after V105. The supported general object should be called a **developmental capability preorder/poset** or **reachability order**, not a lattice unless joins/meets are separately established in a particular domain.

## Stronger structural picture

The progression is now:

1. literal operator identity is too fine;
2. old-unit orbit identity removes coordinate/presentation redundancy;
3. V113 shows orbit identity can still be too fine because distinct orbits can induce the same exact closure extension;
4. quotient by mutual reachability gives developmental closure classes;
5. those classes carry a genuine partial reachability order;
6. the resulting order need not be a lattice.

So the stable general object is:

`developmental state = verifier-governed reachable-behaviour poset/preorder`

rather than an unordered operator set or a guaranteed lattice.

## Consequence for the main claim

This makes the theory narrower but stronger.

We should not claim that conceptual/capability growth always forms a lattice. What survives exact falsification is:

> acquisition changes the reachable capability state; candidate constructions can be quotiented by mutual reachability into developmental identity classes, and those classes inherit a directed partial order of capability consequence.

That statement is supported algebraically and by the exact GF(5) structure without requiring nonexistent joins/meets.

## Boundary

Exact unary GF(5) function monoid only. The failure of the lattice property here is enough to refute a universal lattice claim, but it does not determine the order structure of natural code or open-ended reasoning systems.

# Triskelion / LOGOS Full-Stack Checklist

_Last reconciled: 2026-08-14 NZST_

This is the dependency-ordered completion list for a **full scientific + executable LOGOS stack**. Check an item only when its done-condition is satisfied by primary evidence. `results/ATTESTATION_LEDGER.md` remains the authority for scientific claims.

## Completion rule

The stack is complete only when one system can run the whole developmental cycle without substituting prose for mechanism:

`seek/act -> verifier -> closure test -> obstruction -> alphabet/type/capability/organ/constructor update -> scope/admit -> execute -> verify -> retain -> later causal reuse -> revise/revoke -> persist -> optional compile -> benchmark -> new reachable experience`

A historical experiment proving one link does not by itself check off an integrated-stack item.

- [x] **Primary evidence retained in repo for key audited claims.** V34 and V49-V51 audited payloads are vendored under `results/attested/`.
- [x] **External verifier is final authority.** Model/system proposals are not admitted solely because the model says they work.
- [x] **Negatives and harness failures are preserved rather than promoted.**

## 2. Developmental reasoning alphabet — reconstruct the historical 9 -> 10 transition

The goal is **not** to prove that the present ten words are a universal ontology of cognition. The goal is to show that verifier-grounded experience can force the machine's effective cognitive metalanguage itself to grow.

Freeze the historical nine-operator basis:

`Omega9 = {DISTINGUISH, GENERATE, RELATE, CONSTRAIN, SELECT, COMPOSE, RETAIN, TRANSDUCE, RECURSE}`

Do **not** expose PROBE's name, semantics, implementation or labeled demonstrations to the invention arm.

- [x] **Historical 9-operator compression evidence exists.** Earlier audit reports 100% coverage of then-normalized macro-functions with nine operators; best eight-operator subset 93.4%. Treat as historical evidence, not universality.
- [x] **Active-information ablation motivates a distinct epistemic operation.** Earlier cross-domain work reports a substantive solve drop when active information acquisition is removed, supporting `GENERATE != PROBE != SELECT` at the research level.
- [x] **Ten-operator ordering/motif structure has bounded evidence.** V70-V72 positive, V73 hierarchy negative, V74 mixed math transfer; semantic V2/V3 remain mixed rather than proof of natural latent classes.
- [ ] **Freeze three arms:** A=`Omega9`, B=`Omega9 + hand-supplied PROBE`, C=`Omega9 + permission to construct exactly one new primitive from a generic epistemic-state transformation substrate`.
- [ ] **Use independent worlds where passive reasoning genuinely stalls** because alternatives can only be separated by an information-producing action.
- [ ] **Closure obstruction:** prove under a frozen typed budget that the target behavior is not in `Closure(Omega9)`.
- [ ] **Blind invention:** arm C constructs `omega*` without seeing PROBE's name/definition/examples.
- [ ] **Necessity:** `Omega9 + omega*` solves cases that `Omega9` cannot under the same budget.
- [ ] **Source/world-distinct transfer:** retain `omega*` and solve later independently authored epistemic tasks.
- [ ] **Causal ablation:** removing `omega*` restores failure on those later tasks.
- [ ] **Extensional comparison:** compare `omega*` to hand-supplied PROBE behaviorally, without requiring the same representation/name.
- [ ] **Performance control:** arm C approaches or matches arm B's gains without being given PROBE.
- [ ] **Developmental consequence:** information obtained only through `omega*` makes a later distinction/relation/capability discoverable that was not discoverable from `Omega9`.

**Done condition:** verified experience autonomously produces a new epistemic primitive `omega*` that is extensionally PROBE-like, transfers, survives ablation, and causally changes later discoverability.

Supported target statement if this passes:

`Omega_t --verified obstruction--> Omega_(t+1)`

and, more strongly,

`Discoverable(Omega9) subsetneq Discoverable(Omega9 + omega*)`.

**Status: OPEN. Historical 9 -> 10 refinement exists at the research-process level; autonomous reconstruction does not.**

## 3. Multidimensional ontology and verified organ formation

Treat the alphabet as multidimensional rather than ten untyped words. Each operator instance should be representable along dimensions such as:

`(operator_family, operational_type, scale, scope, world, phase, cost, provenance)`.

The goal is to move from primitive vocabulary to **causally useful organs/circuits**, not merely retrospective frequent motifs.

- [x] **Cross-domain operator identity/order evidence exists.** Earlier V19-V23 and V70-V72 provide bounded evidence that operator ordering contains reusable structure.
- [x] **Multi-scale motifs exist beyond shuffled controls.** Examples include `CONSTRAIN -> SELECT`, `CONSTRAIN -> SELECT -> RETAIN`, `RELATE -> COMPOSE`.
- [x] **MDL-charged macro selection exists.** V72 selected macros while charging definition cost.
- [x] **Unrestricted recursive hierarchy is explicitly not established.** V73 found zero qualifying second-level motifs; this negative remains binding.
- [ ] **Verifier-induced operator/type dimensions:** infer operational interfaces/classes from verifier response signatures rather than analyst semantic labels wherever possible.
- [ ] **Define an organ admission criterion** requiring all of: compression/reuse, functional coherence, explicit scope, causal benefit as a unit, transfer, and ablation.
- [ ] **Reify one repeated executable composition as organ `G1`.** It must be callable as one unit, not merely named after the fact.
- [ ] **Unit benefit:** invoking `G1` must improve search/cost/discoverability over re-planning the same primitives under a matched budget.
- [ ] **Source/domain-distinct transfer:** `G1` functions on later independently authored tasks.
- [ ] **Ablation:** removing `G1` removes the unit-level advantage while preserving its underlying primitives.
- [ ] **Organ-level development:** acquisition of `G1` makes evidence reachable that permits construction/discovery of later `G2`.
- [ ] **Ancestor ablation:** `G2` is no longer discoverable when `G1` is removed from the corresponding developmental state.
- [ ] **Conflict/scope:** overlapping organs can be arbitrated or explicitly flagged inconsistent under scope.
- [ ] **No forced hierarchy claim:** only promote `G1 -> G2` or higher levels when causal evidence supports them; V73 prevents inferring an infinite/fractal organ hierarchy from motif recurrence alone.

**Done condition:** at least one verifier-grounded motif becomes a reusable causal organ `G1`, and acquiring `G1` changes what later organ/capability `G2` becomes discoverable.

**Status: PARTIAL EVIDENCE FOR ALPHABET/MOTIFS; CAUSAL ORGAN FORMATION OPEN.**

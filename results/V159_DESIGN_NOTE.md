# V159 Design Note

V157 leaves a carrier-level confound: an opaque same-length JSON envelope preserves the call-2 rival-execution effect even after semantic labels and string contents are destroyed.

V159 therefore tests two carrier axes simultaneously:

- JSON-like structural punctuation/nesting present vs flattened;
- high alphabetic diversity vs collapsed repetitive alphabetic content.

This is intentionally a mechanism separator, not a task-solving benchmark and not evidence for semantic learning. The strongest use of a positive result is to identify which carrier property moves search policy before retained-state effects are interpreted developmentally.

Primary protocol: `protocols/V159_CARRIER_STRUCTURE_ENTROPY_SEPARATOR_PRECOMMIT.md`.

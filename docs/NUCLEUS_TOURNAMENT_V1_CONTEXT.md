# Nucleus Tournament V1 — Why Triskelion is the right test bed

The repository audit before implementing `NUCLEUS_TOURNAMENT_V1` found that Triskelion already contains most of the experimental ingredients needed to test a developmental nucleus, but they are distributed across separate historical lines.

The tournament is therefore not a replacement for prior work. It is a reduction test: can the strongest recurring behavior be regenerated from a much smaller developmental seed?

## Existing evidence that matters

### V54: child changes the next reachable world

The canonical attestation ledger identifies `TWO_GENERATION_COMPOUNDING_V54` as the strongest bounded developmental result on main:

> under the frozen one-new-generator protocol, O2 had zero cold survivors before O1, became discoverable after O1, and the final target required both.

This is already the essential **child-becomes-parent** predicate that the nucleus tournament makes recursive over six generations.

### V34: retained capability changes later discoverability across source-distinct code

`SOURCE_DISTINCT_DISCOVERABILITY_V34` is attested bounded evidence that prior acquired operators move the next visible obstruction frontier across Requests → Rich → Flask, with ancestor ablations moving the frontier backward.

This is the natural-code analogue of **Integration changing future Differentiation**.

### V49–V51: revision and operator construction

The sealed/operator line establishes bounded executable examples of:

- transfer;
- HELP/HARM derived from executable outcomes rather than supplied labels;
- later counterevidence causing revocation;
- a new rewrite operator outside the frozen token-permutation closure but inside a supplied generic meta-language.

These are prior instances of **differentiate → mediate → integrate/revoke**.

### Effective-language expansion / developmental-loop capstone

The later branch line directly tests persistent executable language growth.

`EFFECTIVE_LANGUAGE_EXPANSION_V1` is a bounded positive: a verifier-guided constructed K expands the effective language, exposes a new O2, and exact K ablation removes O2 reach.

`DEVELOPMENTAL_LOOP_CAPSTONE_V1` is scientifically useful because it is a valid negative rather than a polished story. Nine of ten headline gates pass, but the MEMORY separator fails on the headline world and only 48/100 sweep worlds satisfy the full capstone. That means installed executable structure was not cleanly separated from episodic reconstruction in the frozen setup.

The nucleus tournament avoids rescuing that protocol. It asks a different question: whether one-child-per-episode recursive reach is causally generated by a minimal triadic operator set.

### Blind natural constructor line

`DI_BLIND_V2` is a clean negative: no autonomous O1 was acquired, so no O1→O2 developmental claim was allowed.

That remains important. A positive nucleus microcosm does **not** erase the natural-world constructor gap.

### Current main: one-layer-deeper aggregation work

The newest main commits are probing whether aggregation topology or non-root internal state supplies a causal learning advantage. The committed internal-state learning result is negative, and the leakage-free V2 protocol retains strong sham/structure controls.

This is consistent with the nucleus programme: do not promote a favored representation merely because it is intuitively attractive. Let consequence decide whether the form earns retention.

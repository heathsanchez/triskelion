## Executive state

The programme is no longer best described as a collection of independent experiments. Its strongest surviving structure is a developmental controller over an explicit state:

`A_t = (Omega_t, O_t, L_t, S_t, Pi_t, G_t, K_t, D_t, V)`

where experience is processed approximately as:

`state -> residual -> closure test -> discriminator -> intervention -> verifier -> admit/reject -> ablate -> transfer -> revise -> next residual`.

The stable scientific claim is bounded: external verifier evidence can change explicit capability state, scope, quotient identity and constructor machinery in ways that causally change later reachability/discoverability. Open-ended autonomous self-improvement is **not** established.

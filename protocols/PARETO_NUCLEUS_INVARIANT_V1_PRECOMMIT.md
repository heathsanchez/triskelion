# PARETO NUCLEUS INVARIANT V1 — prospective precommit

Status: **FROZEN BEFORE IMPLEMENTATION OR OUTCOME EXECUTION**

## Governing question

The exact ternary developmental census produced 16 Pareto-undominated complete canonical nuclei under the four frozen developmental metrics:

\[
(G_3,R_3,P,M).
\]

The previous frozen feature set did not isolate a narrow family.

This experiment asks:

\[
\boxed{\textbf{Do those 16 Pareto nuclei share a deeper low-complexity algebraic or dynamical invariant that the previous feature set missed?}}
\]

The target is deliberately narrow. We do not add new architecture or new developmental machinery.

## New frozen orbit-invariant structural features

For every canonical pointed operation \((A,g,d)\), \(A=\{0,1,2\}\), compute:

### Translation structure

For each \(a\in A\):

\[
L_a(x)=d(a,x),
\qquad
R_a(x)=d(x,a).
\]

Record orbit-invariant summaries:

- number of distinct translations among the six \(L_a,R_a\);
- total number of bijective translations;
- total number of constant translations;
- minimum, maximum and mean translation image size;
- size of the transformation monoid generated by all six translations and identity;
- number of carrier states reachable from \(g\) under that monoid;
- whether the translation action is transitive on \(A\).

### Row/column mixing

Record:

- sorted multiset of the three row image sizes;
- sorted multiset of the three column image sizes;
- total number of permutation rows and columns;
- total number of constant rows and columns;
- minimum pairwise Hamming distance between distinct rows/columns;
- maximum pairwise Hamming distance between distinct rows/columns;
- sorted output-frequency multiset over all nine table cells.

### Pointed minor structure

Evaluate the unary minors:

\[
d(x,x),\quad d(g,x),\quad d(x,g).
\]

Record:

- number of distinct unary minors;
- image size of each minor, sorted orbit-invariantly;
- whether any pointed minor is a permutation;
- whether any pointed minor is constant.

### Universal-algebra structure

Record exactly:

- number of nonempty proper subalgebras;
- number of proper subalgebras containing \(g\);
- number of congruence relations among the five set partitions of a 3-element carrier;
- automorphism-group size;
- whether the algebra is simple (only equality and universal congruences);
- whether it has no proper nonempty subalgebra containing \(g\).

### Recurrence-map structure

For:

\[
T(a,b)=(b,d(a,b))
\]

on the 9 carrier-pair states, record:

- number of cycles;
- maximum cycle length;
- number of cyclic states;
- maximum basin size;
- whether \(T\) is bijective.

Because argument swap is quotiented in the canonical population, every recurrence feature is stored as the sorted pair of its value for \(d\) and for the opposite operation \(d^{op}(a,b)=d(b,a)\), or as a symmetric aggregate where scalar.

## Low-complexity identity census

Generate every syntactic term over:

\[
\{x,y,g,d\}
\]

with at most 3 occurrences of \(d\).

Terms are generated prospectively, without semantic pruning.

For an identity:

\[
s=t
\]

define the orbit-invariant identity property:

\[
I_{s,t}(d)
\iff
(s=t\text{ in }d)
\lor
(\operatorname{mirror}(s)=\operatorname{mirror}(t)\text{ in }d),
\]

where mirror recursively exchanges the arguments of every \(d\)-node.

This makes the identity property invariant under the prior census's global argument-swap quotient.

The experiment reports:

- number of nontrivial identity properties satisfied by all 16 Pareto nuclei;
- for each such identity, raw-weighted prevalence among all complete nuclei;
- prevalence among the joint-developmental class;
- the rarest Pareto-common identity property;
- whether any Pareto-common identity property is exclusive to the Pareto set;
- the five rarest Pareto-common identity properties, tie-breaking by total term size then lexicographic term strings.

An identity is nontrivial iff its orbit-invariant property is not true for every complete nucleus.

No identity is selected by semantic interpretation.

## Common-feature test

For each frozen Boolean or categorical new feature, report whether all 16 Pareto nuclei share the same value.

For each such Pareto-common feature-value property, report:

- weighted prevalence among complete nuclei;
- weighted prevalence among joint-developmental nuclei.

Report the rarest Pareto-common single feature-value property.

## Two-feature conjunction search

To test whether no single feature suffices, consider conjunctions of two Pareto-common Boolean/categorical feature-value properties.

Require raw complete-population support of at least 24 pointed nuclei.

Choose the conjunction with smallest complete-population prevalence, tie-breaking lexicographically.

This is descriptive and prospectively fixed. It is not a causal claim.

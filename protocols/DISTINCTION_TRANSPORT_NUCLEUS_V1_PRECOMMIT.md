# DISTINCTION TRANSPORT NUCLEUS V1 — prospective precommit

Status: **FROZEN BEFORE IMPLEMENTATION OR OUTCOME EXECUTION**

## Governing question

The exact Pareto-invariant census found no shared low-complexity equation among the 16 strongest 3-element nuclei.

What did emerge was a dynamical pattern:

- no constant translations;
- higher translation image sizes;
- more bijective translations;
- larger translation monoids;
- greater row/column separation;
- more recurrent cyclic-state occupancy.

This suggests that developmental power may not be controlled by an algebraic identity, but by how well an operation **transports distinctions without prematurely collapsing them**.

This experiment tests that hypothesis directly.

The target is:

\[
\boxed{\textbf{Is developmental power predicted by distinction-preserving mixing?}}
\]

## Primitive object: oriented distinction

For a finite carrier \(A\), define:

\[
\Delta(A)=\{(a,b)\in A^2:a\neq b\}.
\]

For \(|A|=3\),

\[
|\Delta|=6.
\]

For a pointed binary algebra \((A,g,d)\), define elementary translations:

\[
L_c(x)=d(c,x),
\qquad
R_c(x)=d(x,c),
\qquad c\in A.
\]

There are six elementary translations.

Each translation acts on an oriented distinction:

\[
\tau:(a,b)\mapsto(\tau(a),\tau(b)).
\]

If \(\tau(a)=\tau(b)\), the distinction is **collapsed**.
Otherwise it is transported to another element of \(\Delta\).

This induces a finite directed multigraph on:

\[
\Delta\cup\{\bot\},
\]

where \(\bot\) is the collapse sink.

## Exact elementary distinction-transfer matrix

Index the six oriented distinctions arbitrarily but deterministically.

Define the exact \(6\times6\) integer matrix \(C\) by:

\[
C_{\delta,\delta'}
=
\#\{\tau\in\{L_0,L_1,L_2,R_0,R_1,R_2\}:
\tau(\delta)=\delta'\}.
\]

Collapsed transitions are omitted from \(C\) and counted separately.

Each row therefore sums to at most 6.

This matrix is the frozen core object of the experiment.

## Exact distinction-transport quantities

For every canonical pointed nucleus compute:

### T1. Elementary retention

\[
\operatorname{ER}
=
\frac{\sum_{\delta,\delta'}C_{\delta,\delta'}}{36}.
\]

This is the fraction of elementary translation/distinction encounters that preserve a distinction.

Also record:

- minimum live outdegree over \(\Delta\);
- maximum live outdegree;
- number of distinctions with zero live outdegree.

### T2. Exact finite path survival

For \(k=1,\ldots,8\), compute:

\[
P_k=\mathbf1^\top C^k\mathbf1.
\]

This counts every length-\(k\) elementary translation path beginning from every oriented distinction that remains noncollapsed at every step.

Normalize descriptively by:

\[
S_k=\frac{P_k}{6\cdot6^k}.
\]

The exact integer sequence \(P_1,\ldots,P_8\) is authoritative.

### T3. Distinction mixing coverage

Let:

\[
R=\bigvee_{k=0}^{5}(C^k>0).
\]

Record:

\[
\operatorname{MC}
=
\frac{\#\{(\delta,\delta'):R_{\delta,\delta'}=1\}}{36}.
\]

Also record:

- number of SCCs in the live distinction graph;
- largest SCC size;
- whether the live distinction graph is strongly connected;
- number of distinction states lying on at least one directed cycle.

### T4. Grounded distinction reachability

Define the ground-touching distinction set:

\[
\Delta_g=
\{(g,a),(a,g):a\neq g\}.
\]

Record the number of oriented distinctions reachable from \(\Delta_g\) without entering \(\bot\), and whether all six are reachable.

### T5. Translation-semigroup distinction retention

Let \(M\) be the exact unary transformation monoid generated by identity and the six elementary translations.

For each oriented distinction \(\delta=(a,b)\), define:

\[
r_M(\delta)
=
\#\{m\in M:m(a)\neq m(b)\}.
\]

Record:

- \(|M|\);
- minimum, maximum and mean \(r_M(\delta)\);
- normalized mean:
  \[
  \operatorname{SR}
  =
  \frac{1}{6|M|}
  \sum_{\delta\in\Delta}r_M(\delta);
  \]
- normalized minimum:
  \[
  \operatorname{SF}
  =
  \frac{\min_\delta r_M(\delta)}{|M|}.
  \]

### T6. Semigroup distinction mixing

For each \(\delta,\delta'\in\Delta\), ask whether some \(m\in M\) maps:

\[
\delta\mapsto\delta'.
\]

Record:

\[
\operatorname{SMC}
=
\frac{\#\{(\delta,\delta'):\exists m\in M,\ m(\delta)=\delta'\}}{36}.
\]

Also record whether the monoid action on oriented distinctions is transitive.

## Candidate new invariant

Define the frozen **Distinction Transport Capacity**:

\[
\boxed{
\operatorname{DTC}
=
\operatorname{SF}\cdot\operatorname{SMC}
}
\]

where:

- \(\operatorname{SF}\) is the worst-case fraction of monoid transformations that preserve a distinction;
- \(\operatorname{SMC}\) is the global distinction-to-distinction reachability coverage.

This is intentionally conservative: a nucleus scores highly only if it preserves every distinction reasonably well and can transport distinctions broadly.

No threshold is chosen prospectively beyond population quantiles below.

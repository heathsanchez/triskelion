For each round record:

- raw syntax population (N_t=sum_s m_s);
- warranted active classes (C_t);
- compression ratio (N_t/C_t);
- ordered candidate applications evaluated by a naive raw search, (N_t^2);

- cumulative raw candidate count;
- cumulative quotient candidate count;
- exact consequence-set hash.

The raw candidate count is a frozen abstract search-work measure. It is not wall-clock time.

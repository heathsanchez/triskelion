## Common carrier/action representation

Let \(A=\{0,1,2\}\), \(g\in A\), and \(d:A^2\to A\).

For each \(c\in A\):

\[
L_c(x)=d(c,x), \qquad R_c(x)=d(x,c).
\]

Each unary translation acts on the exact pair-state space:

\[
\Omega=A\times A,\qquad
\tau(a,b)=(\tau(a),\tau(b)).
\]

All candidate views retain:
1. exact pair-state action maps;
2. the pointed pair-state coloring induced by \(g\);
3. invariance under all carrier relabelings;
4. invariance under global argument swap \(d(a,b)\leftrightarrow d(b,a)\).

The only variable is **how much incidence information is retained between elementary actions and their source/role labels**.

## Frozen candidate lattice

### V0 — fully anonymous
One multiset containing all six elementary action maps.

### V1 — ground-source marked
Two multisets:
- translations generated by \(g\);
- translations generated by \(c\neq g\).

Left/right role is forgotten.

### V2 — side marked
Two multisets:
- all \(L_c\);
- all \(R_c\).

Generator identity is forgotten.

### V3 — ground-source × side marked
Four multisets:
- \(L_g\);
- \(R_g\);
- \(L_c\) for \(c\neq g\);
- \(R_c\) for \(c\neq g\).

Non-ground generator identity is forgotten.

### V4 — generator-incidence marked
For each carrier element \(c\), retain the unordered pair:

\[
\{L_c,R_c\}.
\]

Thus exact generator/action incidence is retained but left/right role is forgotten.

### V5 — fully marked elementary incidence
For each carrier element \(c\), retain the ordered pair:

\[
(L_c,R_c).
\]

This is the strongest elementary view and may reconstruct the original operation orbit.

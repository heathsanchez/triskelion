# V103 Operator-Quotient / Compression Validation — PRECOMMIT

Frozen before validation execution: 2026-08-15 NZST.

## Discovery motivating this gate

Exploratory exact enumeration in the 2-input Boolean operator space showed that the literal best reusable operator can change across samples even when the generated task family is fixed. All eight non-affine binary Boolean operators are transformable into one another by transformations already available in the affine substrate (argument swap, input negation, output negation). This suggests that the scientifically stable object may be an operator **equivalence class modulo the old language**, not a literal surface primitive.

This discovery is exploratory and is not itself validation evidence.

## Frozen validation question

1. Does a source-distinct held-out stream preserve the discovered *quotient-level* non-affine capability even when the literal generating representative changes?
2. Does retaining one representative lower exact reconstruction/search cost versus rebuilding an operator independently for every target, after charging the operator definition and a typed activation condition?
3. Does an equal-information truth-table dispatcher remain a stronger description baseline, in which case description compression must be withheld even if search compression passes?

## Frozen world

- Boolean functions of three variables, represented extensionally by 8-bit truth tables.
- Old effective language: variables, constants and XOR. Its unbounded closure is exactly the affine Boolean functions.
- Meta-construction candidates: all 16 binary Boolean truth tables; validation excludes affine candidates when testing closure expansion.
- Old-language equivalence action on binary operators: argument swap, independent input negations and output negation.
- Acquisition generator seed: `202608151703`.
- Held-out generator seed: `202608151704`.
- Acquisition hidden representative: selected deterministically from the non-affine candidate list by the acquisition seed.
- Held-out hidden representative: selected deterministically from the same quotient orbit but required to differ literally from the acquisition representative.
- Acquisition: 30 unique non-affine target functions generated by depth-3 programs using XOR + hidden representative.
- Held-out: 50 unique non-affine target functions generated by depth-4 programs using XOR + a different representative from the same quotient orbit, plus a deterministic variable permutation.

## Exact synthesis / cost

For every non-affine candidate operator, compute exact minimal semantic-expression node cost for all 256 three-variable Boolean functions using variables/constants as unit leaves and XOR/candidate as unit binary nodes. Search terminates only after semantic closure is complete or all held-out targets are reached.

Discovery selection uses acquisition data only. The selected literal representative minimizes:

`4-bit operator-definition charge + sum minimal AST node costs`.

Ties are retained as an equivalence set rather than broken post hoc.

### Charged governance

The activation scope is the supplied type rule `Bool × Bool -> Bool`; charge one scope symbol. No case-specific activation predicate is permitted. Withdrawal condition is verifier semantic mismatch; charge one lifecycle symbol. Thus the retained package pays 6 fixed units before per-target program cost (4 operator bits + scope + withdrawal).

### Baselines

- `COLD_RECONSTRUCT`: on each target independently, choose the cheapest non-affine operator after paying a fresh 4-unit operator-definition charge plus scope/withdrawal charges for that target.
- `WARM_RETAINED`: pay the 6-unit governed operator package once, then reuse the acquisition-selected literal representative on every held-out target.
- `LUT_DISPATCHER`: pay exactly 8 bits per held-out target truth table; no artificial file names or source-path overhead.

### Search accounting

For each candidate synthesis run, count unique semantic functions admitted before the target minimal cost is established. `COLD_RECONSTRUCT` sums the search effort required to evaluate all eight non-affine candidates independently for each held-out target. `WARM_RETAINED` performs one retained-operator synthesis table and reuses it for all targets. This is a semantic-state expansion count, not wall-clock runtime.

## Frozen gates

- `G1_AFFINE_OBSTRUCTION`: every held-out target used for the construction claim lies outside exact old affine closure.
- `G2_QUOTIENT_ROBUSTNESS`: acquisition and held-out hidden representatives differ literally but belong to the same old-language operator orbit.
- `G3_DISCOVERED_CLASS_TRANSFER`: every acquisition-selected literal winner lies in that same non-affine orbit, and at least one acquisition winner remains competitive on held-out within 10% of the best held-out single-representative total AST cost.
- `G4_SEARCH_COMPRESSION`: warm retained semantic-state search cost is at least 4x lower than cold reconstruction search cost on held-out.
- `G5_GOVERNANCE_CHARGED`: scope and withdrawal charges are included in both retained and cold packages.
- `G6_DESCRIPTION_VS_RECONSTRUCTION`: warm retained total governed AST-unit cost is lower than cold per-target reconstruction total.
- `G7_LUT_CONTROL`: report comparison to the 8-bit-per-target LUT dispatcher. This gate is descriptive, not forced positive. If LUT is cheaper, explicitly withhold an encoding-independent description-compression claim.

## Allowed interpretations

A pass can support boundary robustness **at the quotient level**: the stable new capability is a non-affine operator class modulo transformations already expressible in the old language, not a privileged surface token/operator.

Search compression may be claimed only if G4 passes with the governed package charged. Description compression may be claimed only against the baseline(s) it actually beats. The LUT control must not be hidden or reweighted after seeing results.

This finite-world test does not establish natural-world operator invention or universal MDL optimality.

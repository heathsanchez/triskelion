# MEMORY_VS_INSTALLED_REPLICATION_V1 — prospective precommit

## Motivation

DEVELOPMENTAL_LOOP_CAPSTONE_V1 was a valid negative because its single headline seed did not separate complete episodic memory from installed developmental structure at the frozen downstream budget. Its exploratory 100-seed robustness sweep showed the separator on 48/100 seeds. That observed batch is pilot evidence only and is not reused here.

## Fresh population

Use the unchanged exact world, unchanged generic U, unchanged coherent CEGIS acquisition, unchanged K admission rule, and unchanged downstream O2 selection/cost accounting from DEVELOPMENTAL_LOOP_CAPSTONE_V1.

The replication population is the disjoint frozen seed range:

`METALOGIC_DEVELOPMENTAL_LOOP_CAPSTONE_V1:100` through `:199`.

No seed in :000..:099 may contribute to the replication verdict.

## Arms

For each fresh seed:

- DEVELOPMENT installs the independently verified K as a reusable unit-cost primitive.
- MEMORY receives the complete acquisition transcript and exact source expression for K but does not install it; every use must be represented in the ordinary generic U syntax.
- COLD retains L0 only.

O2 and B are selected exactly as in the frozen capstone: O2 is hash-selected from functions reachable with installed K but outside exact Cl(L0), and B is its minimal installed-language syntax size under the bounded enumerator.

A memory separator occurs iff DEVELOPMENT reaches O2 within B while MEMORY cannot represent O2 within B despite having the full K source/transcript.

## Prospective hypotheses

H1 — All 100 fresh episodes preserve old-closure obstruction, verified K acquisition, DEVELOPMENT downstream reachability, and K remove/restore causality.

H2 — The memory separator occurs on at least 35/100 fresh episodes. This threshold was frozen before inspecting seeds :100..:199 and is deliberately below the 48/100 pilot rate.

H3 — Among separator episodes, the ordinary-U minimal expression size for O2 exceeds the installed-language B by at least one node in every case where U reaches O2 by size 9. If U does not reach O2 by size 9, record the gap as `>9-B` rather than inventing a value.

H4 — At least 25/100 fresh episodes have a strictly positive measured description-cost gap (or right-censored positive gap) favoring installed structure.

## Verdict

`PASS_MEMORY_VS_INSTALLED_REPLICATION_V1` iff H1-H4 all pass.

Otherwise record `VALID_NEGATIVE_MEMORY_VS_INSTALLED_REPLICATION_V1` and disclose which hypotheses failed. No seed substitution, target replacement, budget change, or same-population rescue is allowed.

## Claim boundary

A pass would establish a prospective finite-world population result that explicit installation can create a bounded executable-description/reachability advantage over complete source-bearing episodic memory on a nontrivial fraction of mechanically sampled developmental episodes. It would not establish that installed structure always beats memory, nor natural-code/open-world generality.

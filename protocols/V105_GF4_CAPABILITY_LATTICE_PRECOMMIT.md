# V105 GF(4) Capability-Lattice Validation — PRECOMMIT

Date: 2026-08-15 NZST

Frozen before any GF(4) orbit/closure result is computed.

## Motivation

V104 validated quotient-level operator identity in B2 and GF(3), but exploratory GF(5) analysis falsified the stronger binary picture that all non-old operators form one new class. Instead GF(5) showed multiple old-automorphism orbits with different closure-expansion profiles.

V105 asks whether that richer **capability-lattice** structure recurs prospectively in a fresh exact substrate.

## Fresh substrate

Unary functions over GF(4), with GF(4)=GF(2)[a]/(a^2+a+1).

- elements encoded 0,1,a,a+1 as 0..3;
- addition is field addition;
- multiplication is field multiplication modulo a^2+a+1;
- universe: all 4^4 = 256 unary functions GF(4)->GF(4);
- old capability: all affine maps x -> ax+b (16 maps);
- invertible old coordinate transformations: affine bijections with a != 0 (12 maps);
- candidate set: all non-affine unary functions.

No GF(4) orbit counts, closure sizes or witnesses may be inspected before this precommit.

## Identity quotient

Two candidates are in the same literal-coordinate identity class only when related by invertible old-language pre/post affine transformations.

Non-invertible old maps are excluded from identity transformations.

## Exact closure

For an added representative O, compute the exact unary composition semigroup generated by:

    old affine maps + O

until fixed point.

## Frozen gates

### G1 — nontrivial quotient structure
The non-affine candidate set must decompose into at least two old-automorphism orbits. If it is a single orbit, the richer lattice hypothesis is not supported in this substrate.

### G2 — within-orbit representative invariance
For every orbit with at least two representatives, test at least the lexicographically first and last representative. Their generated closures must have the same cardinality, and after applying old affine coordinate conjugacies their reachable orbit profile must agree.

### G3 — between-orbit capability distinction
At least two quotient orbits must induce different exact closure sizes or different reachable-orbit profiles. Otherwise the quotient partition is decorative and does not track capability consequence.

### G4 — nontrivial reachability order
There must exist at least one pair of distinct quotient orbits A,B such that adding a representative of A makes all of B reachable while adding B does not make all of A reachable. This is a directed/ordered developmental relation, not merely clustering.

### G5 — same-class addition is redundant after admission
After adding one representative O from an orbit and reaching its exact closure, adding any second tested representative from that same orbit must not enlarge the closure further (up to the old-coordinate equivalence already admitted).

### G6 — verifier-indexed refinement
Use a deterministic weak verifier consisting of the first three GF(4) inputs in encoding order and a strong verifier using all four. Search lexicographically for the first pair `(old_affine, non_affine)` with identical weak signatures but distinct strong signatures.

Required: such a witness exists. This shows a weak verifier can merge old/new behaviours that stronger evidence later separates.

### G7 — negative controls
- allowing non-invertible affine maps as identity transformations must be shown capable of false collapse for at least one non-affine function;
- an intentionally incomplete old generator presentation must be detected as smaller than the 16-map old affine closure;
- no candidate operator may be used in defining the identity group.

## Primary verdict

`PASS_V105_GF4_CAPABILITY_LATTICE` only if G1–G7 pass.

## Allowed interpretation

A pass supports:

> In a fresh exact GF(4) substrate, quotient classes under old-language invertible transformations carry different causal reachability consequences and form a nontrivial directed capability structure, while novelty remains verifier-indexed.

It does not establish a universal lattice theorem, natural-world operator invention, or open-ended ontology growth.

## Post-gate exploration

Only after primary evaluation, inspect the exact quotient/reachability graph for possible algebraic invariants, minimal generators, strongly connected components, joins, or obstructions. These findings remain exploratory until separately frozen.

# V104 Adversarial Quotient-Identity Falsification — PRECOMMIT

Date: 2026-08-15 NZST

Status: frozen before implementation/result execution.

## Question

Is operator novelty more stably identified as a new verifier-indexed behavioural equivalence class modulo transformations already realizable by the old language, rather than by literal primitive identity?

This protocol is designed to falsify that interpretation, not protect V103.

## Core criterion under test

For old capability state A and verifier V, define two candidate operators O1,O2 as presentation-equivalent when there exist invertible input/output transformations already realizable by A that map one operator's behaviour to the other without changing verifier-authoritative semantics.

A novelty event is then indexed by both old capability and verifier:

    [O]_(A,V)

not by a literal operator token/name alone.

The criterion must satisfy all of the following or it is rejected.

## Two exact finite substrates

### B2 — Boolean substrate
- values: {0,1}
- old language: all affine Boolean functions generated by constants, variables, XOR and NOT
- binary candidate universe: all 16 binary Boolean truth tables
- old binary class: the 8 affine binary functions
- candidate novelty set: the 8 non-affine binary functions
- authoritative strong verifier: complete truth table
- weak verifier for refinement test: inputs 00,01,10 only; separator 11 is withheld until the refinement phase
- reachability world: all 256 Boolean functions on three inputs

### F3 — ternary unary substrate
- values: GF(3)
- old language: all unary affine maps x -> ax+b over GF(3), including constants
- candidate universe: all 27 unary functions GF(3)->GF(3)
- old class: the 9 affine maps
- candidate novelty set: the 18 non-affine maps
- authoritative strong verifier: all inputs 0,1,2
- weak verifier for refinement test: inputs 0,1 only; separator input 2 withheld until refinement phase
- reachability world: all 27 unary functions

## Frozen transformations allowed for identity quotient

Only invertible transformations already present in the old language may identify candidate representatives.

B2:
- swap the two arguments
- independently negate either input
- negate the output

F3:
- precompose by affine bijections x -> ax+b, a in {1,2}
- postcompose by affine bijections y -> cy+d, c in {1,2}

No candidate/new operator may be used to define its own equivalence relation.

## Frozen falsification gates

### G1 — literal-coordinate invariance
All non-old representatives in each substrate must form the same old-language automorphism orbit. If surface representatives split into multiple unexplained identity classes, the simple quotient criterion fails in that substrate.

### G2 — old-presentation invariance
At least three generator presentations of the same old semantic closure must compute the same novelty partition:
- B2: {XOR, constants, NOT}, {XNOR, constants, NOT}, and the extensional affine truth-table closure.
- F3: generators {x+1, 2x, constants}, generators {x+2, 2x+1, constants}, and the extensional affine-map closure.

The comparison is semantic/exact, not syntactic.

### G3 — capability-boundary sensitivity / deliberate collapse
Expand the old language by adding one representative from the claimed new quotient class, then recompute exact closure.

Required:
- B2: old 3-input reachability expands from 16/256 to 256/256.
- F3: old unary reachability expands from 9/27 to 27/27.
- Every previously novel representative becomes reachable/equivalent to old capability under the expanded state.

If novelty does not disappear when the old capability actually expands enough to contain it, the quotient criterion is cosmetic and fails.

### G4 — verifier-indexed refinement
The criterion must change when authoritative evidence distinguishes behaviours previously merged by a weaker verifier.

Frozen witnesses:
- B2: XOR and OR agree on 00,01,10 and differ on 11. Under weak V0 they are observationally equivalent; under strong V1 they split.
- F3: identity x and square x^2 agree on inputs 0,1 and differ on input 2. Under weak V0 they are observationally equivalent; under strong V1 they split.

Required interpretation: this is quotient refinement due to verifier growth, not automatically operator invention.

### G5 — cross-substrate structural recurrence
The same four-state pattern must occur in both B2 and F3:
1. coarse old closure;
2. candidate outside strong-verifier old closure;
3. literal representatives collapse modulo old-language automorphisms;
4. adding one class representative expands reachability and removes the novelty distinction.

This is only evidence of structural recurrence across two finite algebraic substrates, not universal domain independence.

### G6 — negative controls
The run must include and report:
- non-invertible old maps must NOT be used as identity transformations;
- transformations requiring the candidate operator itself must NOT be admitted into the quotient relation;
- weak-verifier equivalence must NOT be reported as strong-verifier identity;
- syntactically different old generator sets that fail to generate the full old closure must be detected and rejected as invalid presentation controls.

## Discovery phase after frozen gates

After primary gates are evaluated, exploratory analysis may search for:
- multiple quotient orbits in nearby finite algebras;
- cases where one added representative expands closure without reaching the whole universe;
- cases where verifier refinement splits a new-operator class rather than merely old-vs-new;
- a more general invariant characterization of novelty as a change in the lattice/quotient of reachable behaviours.

Exploratory findings must be labelled separately and cannot retroactively change the primary gates.

## Promotion rule

Primary verdict `PASS_V104_ADVERSARIAL_QUOTIENT_IDENTITY` only if G1–G6 all pass in both substrates.

A pass supports only:

> In two exact finite substrates, novelty classification is invariant to old-language-preserving coordinate/presentation changes, sensitive to genuine capability-boundary enlargement, and indexed by verifier strength.

It does NOT establish representation-independent invention, natural-world operator identity, universal ontology evolution, or open-ended reasoning-language growth.

# LOGOS — I Know Kung Fu

A zero-build, deterministic product demo for the Triskelion research stack.

Open `demo/index.html` in a browser and click through the eight beats.

## Story

1. Held-out World B fails in the base state.
2. Independent World A produces a residual.
3. LOGOS checks old closure before admitting a new capability.
4. C17 is externally verified and installed as an explicit capability object.
5. World B passes; uninstall/reinstall exposes the causal dependency.
6. On World C, the original state cannot discover C18 within the frozen budget.
7. With C17 present, the same discovery procedure exposes and verifies C18.
8. The explicit capability is shown as compilable into Machine Instinct.

## Evidence boundary

This UI is a **choreographed evidence-backed demonstration**, not a live claim that one single production runtime currently performs every displayed step end-to-end. It deliberately combines mechanisms established in separate frozen experiments:

- closure-before-invention and external operator invention (V51 line),
- two-generation causal discoverability growth (V54),
- portable capability compilation/recompilation (IKKF V1),
- verified invocation and verifier-induced applicability refinement (V2d / V4b),
- explicit composition and protected consolidation (V16–V18b),
- revision/revocation (V39–V51 line).

The displayed code snippets are intentionally legible synthetic stand-ins. They are not represented as literal source snippets from the scientific runs.

## Design principle

The demo exposes one claim at a time:

> experience → verified capability → causal reuse → changed future discoverability → optional compilation

The research detail remains underneath the product story rather than competing with it.

# Developmental Intelligence — public mechanism demo

This directory turns the strongest bounded Triskelion results into one falsifiable public story:

> **It did not just remember what happened. What happened changed what it could successfully do — and what became discoverable next.**

The demo has two acts.

## Act I — structured experience beats episodic replay

The evidence panel reproduces the recorded V160/V161 result shape:

- **V160:** after C-only neural interference, old executable capabilities A/B regressed. Neural-only = `0/16`, raw verified memory = `0/16`, compiled experiential map = `16/16`, shuffled map = `0/16` on old tasks.
- **V161:** after replacing literal/template rescue with AST-role abstraction and unrelated identifiers, neural-only = `8/16`, raw verified memory = `8/16`, compiled structural map = `16/16`, shuffled map = `0/16`.

These are bounded coding results, not a claim that memory/RAG can never match developmental structure.

## Act II — development changes discoverability

The evidence panel reproduces the attested V54 two-generation result:

`O2 ∉ Discoverable(A0)` but `O2 ∈ Discoverable(A0 + O1)` under the frozen one-new-generator protocol, and the final target required both O1 and O2.

That is the stronger developmental claim: an earlier acquired operator changed what could be discovered later under the same frozen search protocol.

It is intentionally labeled a **mechanism calibration**, not new scientific evidence. The scientific evidence remains the frozen/attested experiment lineage.

## Open the visual demo

Open `demo/developmental_intelligence/index.html` in a browser. It is a single self-contained file: no npm, no server, no API key.

The UI has three deliberate interactions:

1. **Run development** — replays the causal sequence from experience to structural state.
2. **Revert development** — removes the compiled state and shows the protected capability disappear.
3. **Restore development** — restores the state and the capability returns.

Then it reveals the V54 compounding result as the final card: **yesterday's acquired operator changes tomorrow's discoverability.**

## Claim boundary

This demo does **not** claim open-ended self-improvement, consciousness, unrestricted natural-world development, universal skill installation, or general superiority over strong RAG/RL/fine-tuning agents.

It demonstrates and visualizes the narrower research thesis already supported by the repo:

- externally checked experience can be compiled into explicit state;
- that state can causally alter later execution;
- raw episodic memory and shuffled structure can fail where correct structure succeeds in bounded protocols;
- prior acquired operators can change later discoverability in a frozen bounded protocol.

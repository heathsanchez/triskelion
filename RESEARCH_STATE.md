# Triskelion / Metalogic Research State

_Last reconciled: 2026-08-14 16:11 NZST_

## Current strongest synthesis

Triskelion is testing a **verified developmental capability system**: externally verified experience can alter an explicit algebra of capabilities, laws, scopes, distinctions and constructors, and those changes can alter what becomes reachable or discoverable later.

The governing loop is:

`seek/act -> external result -> residual -> closure test -> obstruction -> minimal construction -> verification -> install/retain -> invoke -> revise/revoke -> changed future discoverability`

Neural proceduralization is downstream:

`explicit verified capability/state -> compiler Γ(model) -> optional neural realization`

The explicit object remains authoritative; weights/checkpoints are implementations/caches, not the source of truth.

A useful current state is:

`A_t = (O_t, L_t, S_t, Π_t, K_t, D_t, V)`

where:

- `O_t`: verified capabilities/operators;
- `L_t`: scoped composition/equivalence laws;
- `S_t`: applicability, conflicts, revision and lifecycle conditions;
- `Π_t`: verifier-induced quotient/ontology of operational distinctions;
- `K_t`: constructor machinery for new capabilities/representations;
- `D_t`: discovery policy/budget;
- `V`: external verifier authority.

The key predicates are `Closure(A_t)`, `Discoverable(A_t)` and `Constructible(K_t)`.

## What is now established in bounded form

### 1. Closure before invention

The `even_pairs / MAP_PAIRS` negative remains constitutional: if a target is already expressible by lawful composition, do not promote a new primitive. Novelty must be justified against the frozen effective language.

V51 constructed `< -> <=` after proving the frozen old token-position algebra could not express it because old transformations preserved token-value multisets. The new operator was committed from external obstruction, transferred to sealed Requests, survived causal tests, and later counterevidence triggered revision/revocation logic. Construction remains inside a supplied generic token-emission substrate; this is not unrestricted invention.

### 3. Source-distinct causal reuse and discoverability growth

The external `EXCEPTION_FLOW` stream established a capability formed from one independently authored package and later causally required by another, with ablation restoring failure.

V33/V34 established source-distinct discoverability growth: acquired capability changed which next obstruction the frozen discovery process could expose.

### 4. Constructor-family abstraction and verifier-induced ontology

V35–V39 moved from instances to reusable constructor families and operational interfaces. V39 is especially important: neutral probes plus Python compilation induced operational equivalence classes (e.g. value slots) from verifier responses rather than supplied semantic labels.

V40–V50 progressively weakened experimenter semantics: scopes/categories moved from named structural labels toward generic relations, opaque labels, raw lexical source, site mining, sealed transfer and outcome labels generated by executable verifier transitions.

### 5. Scoped law/quotient revision

The V45–V68 quotient/refinement line established that equivalence is indexed by verifier and scope. Real external separator events split previously coarse equivalence classes. V68 implemented incremental reversible Lawbook refinement: local splits preserved unrelated classes and provenance, reversal restored the prior partition, and refinement could expose previously hidden capability. Do not claim global equivalence when only scoped equivalence is verified.

### 6. Bounded two-generation compounding — V54

Branch: `v54-compounding-ratchet`

Completed workflow: `31761530951` (`Metalogic V54 Two-Generation Compounding`), head `2dd5f41b6c7cec1004b8deaee4f976dd2a9ed21c`.

### IKKF V1 — capability-to-neural compilation, with attestation correction

Primary harness/protocol checked directly.

Supported:

- B0, C1, C2, J, U and R are separately executed in code;
- C1 is compiled from fresh Qwen/Qwen3.5-9B + fresh rank-32 LoRA using the explicit capability-derived practice data and reaches 100% on 32 held-out source-distinct cases;
- C2 is a second separately invoked fresh compilation call and also reaches 100%;
- matched decoy J remains 0%;
- fresh/uninstalled U remains 0%;
- reload R of C1 remains 100%;
- held-out programs/suffixes are excluded from gradient batches.

Attestation defect:

- C1 and C2 training loss curves are bit-identical despite nominally different seeds;
- the gate named `independent_recompile` checks only that C1 and C2 both exceed threshold;
- it does not test effective seed/config, adapter-weight inequality or independent checkpoint hashes.

Therefore the current supported wording is **reproducible fresh recompilation**, not yet **genuinely independent stochastic recompilation**. The old wording overstated what the predicate proves. A hardened successor should make independence executable or deliberately rename the result as deterministic reproducibility.

## Evidence / attestation discipline

A CI `success` is not automatically a scientific pass. A prose summary is not primary evidence. A gate name must not claim more than its predicate checks.

From now on, every headline claim should be classified as one of:

- **ATTESTED** — primary result artifact/harness/protocol checked and the predicate supports the wording;
- **BOUNDED PASS** — frozen run passed within its stated substrate, with claim boundary preserved;
- **NEGATIVE** — scientific gate reached and failed;
- **INCOMPLETE / INFRASTRUCTURE** — mechanism was not actually tested;
- **REPORTED / NEEDS ATTESTATION** — summary exists but primary evidence has not yet been audited against the exact sentence.

The IKKF V1 “independent recompilation” correction is the precedent: separate second execution is attested; stochastic independence is not.

## The three capstone gates

### Gate 1 — Natural development

Run V54-shaped developmental compounding on naturally occurring, pre-existing, heterogeneous worlds with human/fixed solutions sealed until termination. Desired structure:

`historical obstruction A -> O1 -> later different-project obstruction B -> O2`

with `O2` not discoverable under the frozen old state/budget but discoverable after `O1`, plus ablations.

V55 says the current adapter/constructor does not expose enough usable natural worlds yet.

### Gate 2 — Economic compounding

Under matched sequential budgets compare:

1. base model;
2. raw/episodic memory;
3. ordinary adaptation/fine-tune/LoRA;
4. Triskelion/LOGOS explicit developmental layer;
5. optional LOGOS + compiled instinct.

Measure held-out solved tasks, calls/tokens, verifier interactions, latency/cost, regressions, install/uninstall behavior, transfer and performance as a function of accumulated verified experience.

### Gate 3 — Attested lifecycle

Treat this as a precondition for Gates 1 and 2 counting. Every Discover -> Verify -> Install -> Invoke -> Compile -> Revise transition must be reproducible from primary evidence rather than narrative state. Evidence should include verifier outputs, hashes, scope, provenance, counterexamples/controls and causal ablations where applicable.
